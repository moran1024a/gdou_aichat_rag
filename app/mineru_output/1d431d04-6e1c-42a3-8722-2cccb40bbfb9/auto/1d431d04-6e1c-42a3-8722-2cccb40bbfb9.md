# 一、物种基础信息

1. 核心身份标识

- 物种名称：中华白海豚（拉丁学名：Sousa chinensis），别名印度-太平洋驼背海豚，隶属海豚科白海豚属哺乳动物，因珍稀性被誉为“水上大熊猫”。

- 名称由来：1751年瑞典牧师彼得·奥斯贝克在广东珠江口发现该物种，命名为“中华海豚”；1870年英国科学家弗劳尔首次使用“Chinese White Dolphin”英文名，现国际公认名为“Indio-PacificHumpback Dolphin”，其“驼背豚”别称源于背部隆起的结构及上方的背鳍。

- 保护级别：1988年被列为中国国家一级保护动物；1991年列入《濒危野生动植物物种国际贸易公约》（CITES）附录Ⅰ，受《迁移物种保护公约》（CMS）保护；2015年被《世界自然保护联盟濒危物种红色名录》列为易危物种（VU），世界现存数量不足一万只。

2. 形态特征

- 体型数据：成体体长 2.0-2.8 米，体重 200-285 千克；新生幼豚体长约 100 厘米。非洲水域雄性平均体长226厘米，雌性216厘米，中国香港附近种群无明显性别差异。

- 体色变化：随年龄呈规律性变化，幼体暗灰色，2岁左右体色逐渐变浅，亚成体灰粉相间，10岁左右性成熟时变为纯白色（常因充血透淡粉色），部分成体有暗色斑点，中老年个体斑点褪去。

- 关键体征：喙中等长，下颌略长于上颌；背鳍大且呈三角形，基部有增厚脊；鳍肢宽圆，尾叶宽且梢端圆，尾柄有发达背脊和腹脊；口腔内有200-300颗圆锥状锋利牙齿，用于控制猎物，上颌31-39颗，下颚29-38颗，西部种群牙齿数量多于东部。

- 感官与生理结构：眼睛小如黑点，视力较差，但依赖发达的回声定位系统生存，可通过口腔发出超声波，精准锁定百米外猎物位置；呼吸孔位于头部，出水呼吸时喷出水汽并伴声音；头骨吻突窄长，颞窝和翼骨较大。

# 二、分布与栖息环境

# 1. 全球分布范围

主要分布于东印度洋及西太平洋近岸水域，北至中国长江以南沿海，东南抵马来群岛，西达孟加拉湾及印度半岛南侧。非洲东部沿岸、阿拉伯海、也门湾、红海及缅甸、斯里兰卡等国水域均有分布，澳大利亚北部和东部沿岸也有其踪迹。

# 2. 中国分布与种群

- 地理分布：东海见于上海横沙岛、江苏长江如皋江段、浙江乐清、福建厦门等；南海分布于广东汕头、珠江口、雷州湾等，另有香港、台湾西海岸及海南西南沿海种群。

- 核心种群：共划分为8个地理种群，其中广东珠江口漠阳江口种群为中国最大种群（数量超2000头），湛江雷州湾种群为中国第二大种群，且雷州湾是世界第二大中华白海豚种群栖息地 。

- 亚种划分：含2个亚种，中华白海豚模式亚种（S.c.chinensis）分布于东印度洋及西太平洋近岸；中华白海豚台湾亚种（S.c.taiwanesis）仅见于中国台湾西部沿海。

# 3. 栖息环境偏好

- 适宜水温超过 15℃，偏好平均深度 20 米的温暖水域，极少进入 25 米以上深水区域。

- 常出没于海湾、河口、红树林、沙洲、珊瑚礁等近岸地带，尤其钟爱咸淡水交汇区域，休息时会集结在沙滩附近海域，作息通常与涨潮和日照时间相配合。

- 不同区域栖息地存在差异：澳大利亚种群多在岛屿礁石浅水区活动，中印沿海水域种群多见于河口和深水航道，阿拉伯及非洲种群常出现在河口与岩质底质近岸水域。

# 三、生活习性

1. 觅食行为

- 食物构成：以鱼类为主，不同区域食物存在差异。中国厦门种群主食鲻鱼、长勒鱼等；北部湾种群偏好斑鱼、青鳞鱼；珠江口种群常捕食棘头梅童鱼、银鲳等；部分区域种群也摄食头足类、甲壳类动物，进食时不经咀嚼快速吞食。

- 觅食特征：觅食高峰在清晨，晚间有次级高峰，晨昏最为活跃，常在潮涨时觅食；善用环境规律，热天或降雨前鱼类浮出水面时，会群体捕猎；常蹲守出海口，捕食被冲来的淡水鱼或退潮后滞留的海鱼，甚至被渔民视为“捕鱼帮手”，其集群活动常提示鱼类密集区域。

- 觅食协作：觅食时个体分散，围捕鱼群时会通过特定叫声协调行动，脉冲型叫声频率随鱼群移动加快，传播角度同步调整，仿佛“指挥”群体协作。

# 2. 社群与迁移

- 社群结构：社会性极强，多集群活动，中国水域群体规模通常30-40只，阿拉伯及马来西亚水域曾出现超

100只的群体，繁殖季节求偶群体规模为2-16只。群体组成动态变化，但母豚与幼豚联系紧密，幼豚被捕获时母豚会持续徘徊附近。

- 迁移规律：无长距离季节性迁移习性，对栖息地有深厚“乡恋情结”，宁可留在熟悉但船舶密集的水域，也不愿迁往干扰少但环境差异大的区域。主要随食物分布和繁殖需求在栖息地范围内移动，对栖息地忠诚度较高 。

# 3. 沟通与感知能力

- 叫声分类与功能：拥有复杂沟通系统，叫声可分为三类。“哨音型”频率5-20千赫兹，多出现于群体聚集互动时，属“社交对话”；“脉冲型”频率 1-5 千赫兹，伴随捕食行为，用于探测猎物或传递食物信号；“复合型”融合哨音与脉冲，节奏丰富，多在遭遇危险时出现，起“警示作用”。

- 独特交流方式：每只海豚有独特高频“专属哨音”，类似人类“名字”，可在复杂环境中快速定位同伴。  
母豚会通过调整哨音音调与节奏教导幼豚，偏离时叫声急促，跟随群体时则舒缓安抚。

- 回声定位应用：该系统可迅速准确检测前方物体的密度、大小、形状等特征，已被生命科学及军事领域用于仿生学研究。

# 四、生长繁殖

1. 繁殖特性

- 性成熟与发情：雌性9-10岁达到性成熟，雄性12-13岁性成熟，常年可交配，发情期多在4-9月，春季和夏季为主要繁殖期 。

- 求偶与交配：求偶时雄性会高速绕雌性绕圈、空中转体、拍胸鳍、背滚式空翻，年龄较小个体常跃起击浪。  
交配时一方仰游或仰跳，另一方在上方水平游动或跳跃，伴随相互追逐与身体接触 。

- 妊娠与产仔：妊娠期10-12个月，产子期多在3-5月，每胎仅产1仔。生产时幼豚尾部先娩出，避免呛水夭折，这是其适应水生环境的关键特征 。

# 2. 幼豚生长与抚育

- 初期发育：初生幼豚体长约1米，体色暗灰色，出生后母豚即刻教导其游泳，哺乳期8-20个月，6个月左右可进食固体食物，但2岁左右才完全断奶 。

- 亲子关系：哺乳期母豚与幼豚形影不离，保护周到，幼豚成活率高于多数水生动物。幼豚会与母豚共同生活3-4年，期间通过母豚的叫声指导逐步掌握生存技能 。

# 五、研究历史与分类

1. 发现与研究历程

- 1637年，英国探险家彼得·文地在港澳及珠江口水域首次记录中华白海豚，描述为“牛奶白色或淡红色海豚百余只”。

- 中国研究始于1960年，福建水产研究所王丕烈等通过西江与长江口白海豚骨骼对比，明确其国内分布状况。

- 近年声学研究取得突破：吕文扬团队通过“立体录音网络”与无人机配合，累计记录500余小时叫声素材，解析出12种功能明确的“沟通信号”，为保护提供新依据。

# 2. 分类演化

- 早期因形态相似，曾被归入真海豚属、侏儒海豚属，后英国学者格雷以亚属形式提出驼背海豚属（Sousa），1934 年该属被提升为属级别，1968 年中华白海豚正式归入该属。

- 2014 年杰弗逊等人提出白海豚属至少含 4 个物种，但因基础资料缺失，中华白海豚分类仍有待进一步研究。

# 六、生存威胁与保护行动

1. 主要生存威胁

- 栖息地缩减：受填海造地、航运活动、风电开发等人类活动影响，过去20年栖息地面积缩减超50%，其偏好的近岸水域恰是经济活跃区域，发展与保护矛盾突出 。

- 种群生存压力：种群年死亡率达2.5%，远超1%的国际警戒线，繁殖效率低（每胎1仔、性成熟晚）加剧种群恢复难度 。

- 环境与人为干扰：工厂污水排放污染水域，渔业作业导致食物减少；船舶引擎、海上施工产生的噪音干扰其叫声传播与接收，破坏沟通系统，影响群体协作与生存。

# 2. 保护措施

- 保护区建设：已建立多处自然保护区，仅广东就有15个海洋保护区，总面积超1200平方公里，含珠江口中华白海豚国家级自然保护区等6个专项保护区 。

- 监测与管理技术：珠江口保护区建成全国首个声光联动实时监测系统，实现24小时全天候监测，水下探头弥补夜间观测盲区；通过背鳍形状差异建立个体识别数据库，收录2300多头白海豚“身份信息” 。

- 人类活动管控：优化沿海项目选址，探索温排水降温排放等生态友好工程技术；在“海豚交流密集区”设立船舶限速区、禁渔区，实施船舶降噪航行措施；福建泉州曾因港口炸礁影响海豚叫停项目并重新评估 。

- 生态修复与协作：将海豚分布海湾优先纳入生态修复项目；广东省海洋与渔业局设立保护基金，联合科研机构、渔民推进保护，渔民转型参与海水取样、巡护等工作 。

# 七、广东区域保护与研究

1. 种群现状

- 广东是全球最重要的中华白海豚栖息地之一，种群数量从2010年约1500只增至2024年1800只左右，全球逾三分之一种群生活在珠江口和江门自然保护区，仅珠江口水域种群就超2000头 。

- 2024 年以来，湛江海域已记录到超过 10 头新生儿，种群呈现稳定增长态势。

2. 科研力量与成果

- 广东海洋大学科研团队长期深耕白海豚研究，开展栖息地监测、食物链分析、生态评估等工作，其水生生物博物馆保存有白海豚标本并开展相关研究。

- 联合其他机构开展专项研究：中国科学院深海科学与工程研究所在珠海、湛江等地开展个体识别、种群动态调查；吕文扬团队在南海开展的叫声研究成果已纳入当地生态保护规划。

八、生态与人文价值

1. 生态意义

作为近岸海洋生态系统的旗舰物种，其种群状况可直观反映水域生态健康程度，对维持渔业资源平衡、指示环境污染具有重要意义。

# 2. 共生典范

广东推动海洋牧场与栖息地和谐共存，200余个海洋牧场实现渔业产值增长与生态修复双赢，白海豚与“海上甜甜圈”养殖场、海上风电机形成“人与自然共生”的具象景观。

# 3. 人文影响

成为广东海洋生态保护的文化符号，吸引全球学者、环保志愿者及留学生参与保护工作；湛江等地渔民自发开展白海豚知识科普，形成全民守护氛围；相关科普内容被引入中小学课堂，助力生态教育普及。
