# 三、生命周期与繁殖

1.寿命

白海豚是相对长寿的海洋哺乳动物。

（1）野生环境:在自然状态下，中华白海豚的平均寿命约为30-40年。当然，也有个别个体能够活得更久些研究表明，有些雌性个体可能活到40岁以上。

（2）影响因素:它们的寿命受到多种威胁的影响，包括栖息地退化、水体污染、船舶撞击、渔网缠绕以及食物资源减少等。这些人为因素往往会缩短它们的实际寿命。

# 2.性成熟年龄

白海豚的性成熟过程相对较慢，这与其长寿和高等社会性哺乳动物的特性相符。

（1）雄性:雄性中华白海豚通常在 9-13 岁之间达到性成熟。

（2）雌性:雌性则稍早一些，大约在8-10岁左右达到性成熟。

（3）意义:较晚的性成熟年龄意味着它们需要较长的时间才能开始补充种群数量，这也使得它们的种群增长率较低，更容易受到外界干扰的影响。

# 3.繁殖季节

与许多有固定繁殖季节的动物不同，白海豚的繁殖季节相对宽泛。

（1）时间:中华白海豚的繁殖是季节性不明显的，或者说繁殖期非常长。它们全年都可以交配和生育，但在不同地区可能会有一个相对的高峰期。

（2）高峰期:例如，在珠江口等地的种群，其繁殖和分娩的高峰期通常出现在春季到夏季(大约 3 月到 8 月)。  
这可能与当时水温适宜、食物(鱼类)资源较为丰富有关，有利于幼豚的存活。

# 4.求偶行为

白海豚的求偶行为复杂而有趣，涉及一系列的身体接触、追逐和声音交流。

（1）群体活动:求偶和交配行为常常以小群体的形式进行，其中可能包括一头发情的雌性和多头竞争的雄性。

（2）身体接触:雄性会积极地用身体摩擦、触碰雌性，这是一个重要的示好和建立联系的方式。

（3）追逐与展示:多头雄性可能会一起追逐一头雌性，形成一个“求偶队列"。在这个过程中，它们会展示自己的力量和活力。有时，雄性还会做出跃出水面、用尾鳍拍水等行为，这既是展示，也可能是一种吸引注意或向竞争对手示威的方式。

（4）声音交流:海豚依靠回声定位系统进行沟通。在求偶期间，它们会发出各种复杂的哨音和咔声，这些声音可能用于彼此间的交流、协调行动或表达兴奋状态。

（5）温和的啃咬:它们有时会互相用喙(嘴巴)轻轻地啃咬对方，这被认为是社交和建立亲密关系的一种行为，在求偶期间尤为常见。

# 5.妊娠期

白海豚的妊娠期相对较长，这与它们体型较大和后代发育程度较高有关。

（1）持续时间:中华白海豚的妊娠期大约为 10 至 12 个月。

（2）意义:漫长的妊娠期意味着母海豚在一次繁殖中需要投入大量的时间和能量。这也导致了其繁殖间隔较长，种群增长率较慢。

# 6.每胎产仔数

白海豚的每胎产仔数非常固定，这是鲸豚类动物的典型特征。

（1）数量:绝大多数情况下，每胎只产1仔。极少数情况下可能出现双胞胎，但在自然环境中，由于母豚的资源有限，很难同时养活两个幼患，存活率极低。

（2）原因:幼豚体型较大，需要在母体内充分发育，且出生后需要母亲长时间的精心照料和哺乳。一胎一仔是能量投入和生存策略上的最优选择。

# 7.幼崽的哺育方式

幼患的哺育方式完全依赖于母亲，方式非常特殊。

（1）水下哺乳:幼豚出生后，会在水中直接从母豚的乳头吸吮乳汁。海豚的乳头隐藏在两生殖裂之间的乳沟里，幼豚会用舌头卷住乳头，形成密封。

（2）喷奶机制:母豚的乳腺周围有肌肉，可以通过收缩肌肉，将富含脂肪的乳汁主动喷射到幼豚的嘴里。这个过程非常迅速，以适应在水下呼吸的节奏，减少幼豚呛水的风险。

（3）高营养乳汁:海豚的乳汁脂肪和蛋白质含量极高，能帮助幼豚快速积累脂肪，用于保温并迅速成长。

# 8.母子关系

白海豚的母子关系非常紧密和长久，是它们社会结构的核心。

（1）紧密跟随:新生幼豚非常脆弱，在生命最初的几周甚至数月里，它会紧紧贴在母豚身边，被称为“稚儿随位“游泳。这个位置可以利用母豚游动时产生的“推力“来节省体力。

（2）学习与保护:母豚不仅是食物的提供者，还是幼豚的“导师“和保护者。它会教导幼豚如何捕食、导航躲避天敌(如鲨鱼)和应对船只等危险。母子之间通过独特的哨音进行识别和交流。

（3）抚育期长:这种紧密的母子关系会持续数年，远超过哺乳期。

# 9.哺乳期

白海豚的哺乳期很长，确保了幼豚能从母亲那里获得充足的营养和免疫力。

（1）持续时间:哺乳期通常持续 2 至 3 年，有时甚至更长。

（2）逐步断奶:哺乳期并非在某个时间点突然结束。随着幼豚长大，它开始尝试捕食鱼类，母乳的摄入量会逐渐减少，这是一个自然的逐步断奶过程。在此期间，幼豚会同时摄取固体食物和母乳。

（2）繁殖间隔:漫长的哺乳期也决定了母海豚的繁殖间隔。通常，母海豚在成功抚育一头幼豚至独立(即断奶后)后，才会再次怀孕。因此，中华白海豚的繁殖间隔通常为 3到6年。

# 四、栖息地需求

白海豚是典型的沿岸栖性物种，它们的生存与大陆架沿岸的特定环境息息相关。

1.水深与地形

（1）偏好浅水:白海豚通常栖息在水深小于20米的浅水沿岸区域，尤其在河口、海湾、红树林水道、沙滩边缘和礁石区附近活动。

（2）地形复杂:它们喜欢水下地形有一定复杂性的区域，如沙洲、泥滩和岛屿周围。这些地方的水流相互作用，能聚集营养物质，从而吸引鱼群。

（3）原因:浅水区阳光充足，营养丰富，是它们主要食物(各种中小型鱼类和鱿鱼)的理想觅食场所。复杂的地形也为它们提供了躲避天敌(如大型鲨鱼)和恶劣天气的庇护所。

2.水体环境（盐度与水质）

（1）广盐性适应:这是白海豚最显著的特征之一。它们能适应从纯淡水到完全海水的广阔盐度范围。它们常出现在咸淡水交汇的河口，这里因河流带来大量营养物质而成为生产力极高的“海底食堂”。

（2）水质要求高:它们需要清洁、污染少的水体。作为顶级捕食者，水体中的污染物(如重金属、持久性有机污染物)会通过食物链在其体内富集，严重影响其免疫系统和繁殖能力。

（3）原因:它们的生理机制能够调节体内渗透压，以适应盐度的日常和季节性变化。对水质的依赖使其成为海洋环境的“指示物种”，它们的存在与否直接反映了生态系统的健康状况。

3.食物资源

（1）丰富的猎物:栖息地必须支撑足够数量的猎物，主要包括群游性的小鱼(如狮头鱼、黄鳝、鲻鱼、石首鱼等)以及少量的头足类动物(如鱿鱼)

（2）关键觅食地:河口、潮汐通道和滩涂是它们最重要的觅食地。这些区域是许多经济鱼类产卵和育幼的场所，为白海豚提供了集中且易得的食物来源。

# 4.人类活动干扰程度

这作为外部因素却直接成为其栖息地选择的决定性约束条件，需要低干扰区域，理想栖息地应尽可能远离:

（1）密集航运与高速船只:导致噪音污染和致命的船舶撞击风险。

（2）高强度渔业活动:可能导致被渔网缠绕(误捕)以及食物竞争。

（3）沿岸工程与填海造地:直接破坏栖息地，改变水流和泥沙淤积模式，并造成持续的水下施工音。

（4）工业与生活排污:导致水质恶化。

5.社会与育幼需求

（1）育幼场:母豚会选择特别平静、隐蔽的浅水区作为育幼场。这些区域水流较缓，天敌较少，便于幼豚跟随母亲学习生存技能，并节省体力。（2）社交空间:栖息地需要提供足够的海域供它们进行社交、求偶和群体互动。

# 四、保护现状

1.种群现状

种群数量及分布全球范围内，目前已知的中华白海豚数量约5700头，且存在下降趋势。国外对该物种的研究较少，据报道最大种群分布于孟加拉湾北部有636头，泰国东海岸的Donsak海域(193头)和西海岸的Sarai 岛(24 头)、Sukon 岛(23 头)以及马来西亚的 Kuching 湾(84 头)，印度尼西亚西加里曼丹的

KubuRaya 海域仅有目击和搁浅记录，未见详细的种群数量报道。全球约 83%（4730 头）的中华白海豚栖息于我国东南沿海，主要有珠江口（含香港和河口西部海域）、雷州湾、北部湾、厦门湾、台湾西海岸和海南西南沿海等6个地方种群，不同种群数量差异较大，且有下降趋势。此外，在福建宁德、泉州湾、东山湾和广东汕头等海域还有少量个体分布。最大的珠江口种群现存约2555头。

（来源：[1]雍李明,张语克,赵丽媛,等.中华白海豚生态学研究进展[J].生物多样性,2023,31(05):145-160.）

2.保护级别与法律法规

（1）国际保护级别：《世界自然保护联盟(IUCN)红色名录》里中华白海豚被列为易危(VU)级别。这意味着它们在中。期内面临较高的灭绝风险。此外《濒危野生动植物种国际贸易公约(CITES)》中被列入附录 I。这意味着所有与其相关的国际贸易。都被严格禁止。

（2）中国国家保护级别：在中国，中华白海豚被列为 国家一级保护野生动物。这是中国野生动物保护名录中的最高级别，与大熊猫、朱鹮等享有同等的法律保护地位。

（3）直接法律依据

①《中华人民共和国野生动物保护法》

核心规定:禁止猎捕、杀害、出售、收购和利用国家重点保护野生动物及其产品。因科学研究、驯养繁殖等特殊需要时，必须向国务院野生动物行政主管部门申请特许猎捕证。

栖息地保护:法律规定要保护野生动物的主要生息繁行场所，这为建立白海豚自然保护区提供了法律基础。

②《中华人民共和国刑法》

非法猎捕、杀害、收购、运输、出售中华白海豚等国家重点保护的珍贵、濒危野生动物，将构成“危害珍贵、濒危野生动物罪”，情节特别严重的，可处以十年以上有期徒刑，并处罚金或者没收财产。

③《江门市中华白海豚自然保护区管理办法》

该办法首先实施严格的分区管控，将保护区划分为核心区、缓冲区和实验区，其中核心区禁止任何人为活动，缓冲区仅限科研观测，实验区则可在监管下开展生态教育等活动。同时，办法明确禁止非法捕捞、污染排放、采砂填海、追逐投喂等损害白海豚及其栖息地的行为，并对航运、工程建设等必要活动实施严格审批和监管。管理办法还明确了主管部门职责，建立多部门联动执法机制，依据相关法律法规对违法行为进行处罚，通过这一系列具体措施将国家级保护法规落到实处，为守护江门海域的中华白海豚种群提供了坚实的法律保障。
